# Напоминалка (Windows, Python)

## Запуск
Двойной клик по **`Запустить.bat`** (или `pythonw napominalka.pyw`).
Библиотеки уже установлены; на другом ПК: `pip install -r requirements.txt`.

## Как добавить задачу
- **Текстом:** пишешь в поле, например `Сдать отчёт 20 ноября` → срок сам подставится → Enter.
- **Голосом:** «🎤 Сказать» → говоришь «забрать посылку через три дня» → «⏹ Стоп» → проверяешь → Enter.
  Распознавание через Google — нужен интернет.
- Срок можно поставить кнопками (Сегодня / Завтра / +3 дня / +неделя) или вписать `15.11.2026`.

Понимает: `сегодня`, `завтра`, `послезавтра`, `через N дней`, `через неделю`,
`20 ноября`, `5 января 2027`, `15.11`, `15.11.2026`, `в понедельник`, `до пятницы`.

## Когда напоминает
| Когда | Как часто |
|---|---|
| за 1 день до срока | раз в 6 часов (первое — сразу) |
| в день срока | каждый час |
| срок прошёл, не отмечено | каждый час, пока не нажмёшь «Выполнено» |
| 23:00–07:00 | молчит |

Напоминание = уведомление Windows со звуком + окно поверх всех окон с кнопками
**Выполнено / Отложить на 3 ч / OK**.

## Прочее
- Крестик окна прячет программу в **трей** (красный значок у часов). Выход — правый клик → «Выход».
- Галочка **«Запускать с Windows»** — стартует вместе с системой, сразу в трей.
- Двойной клик по задаче в списке — отметить выполненной.
- Данные: `%APPDATA%\Napominalka\tasks.json`, журнал там же — `napominalka.log`.
- Интервалы и тихие часы меняются в начале `reminder_core.py`
  (`INTERVAL_DAY_BEFORE`, `INTERVAL_DUE_DAY`, `QUIET_FROM`, `QUIET_TO`).
- Проверка логики: `python test_core.py`.
