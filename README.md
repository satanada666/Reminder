# 🔔 Напоминалка

Простая напоминалка для **Windows, Linux и macOS** на Python + CustomTkinter.
Задачу можно **написать или надиктовать в микрофон** («сдать отчёт 20 ноября»), срок программа
вытащит из фразы сама.

| Когда | Как часто напоминает |
|---|---|
| за 1 день до срока | раз в 6 часов (первое — сразу) |
| в день срока | каждый час |
| срок прошёл, а задача не отмечена | каждый час, пока не нажмёшь «Выполнено» |
| 23:00–07:00 | молчит (тихие часы) |

Напоминание = системное уведомление со звуком + скруглённая карточка поверх всех окон
с кнопками **Выполнено / Отложить 3 ч / ОК**.

## Скачать готовую программу
Раздел **Releases** (или вкладка **Actions** → последняя сборка → Artifacts):

- **Windows** — `Napominalka-windows.zip` → `Napominalka.exe`, установка не нужна.
- **Linux** — `Napominalka-linux-x64.tar.gz` → `./Napominalka`.
  Для голоса нужен PortAudio, для уведомлений — notify-send:
  `sudo apt install libportaudio2 libnotify-bin`
- **macOS** — `Napominalka-macos-arm64.zip` (M1–M4) или `…-intel.zip`.
  Сборка не подписана: при первом запуске правый клик по приложению → «Открыть».
  При первой записи голоса macOS спросит доступ к микрофону.

Собранная программа хранит задачи в папке пользователя:
`%APPDATA%\Napominalka` · `~/.local/share/napominalka` · `~/Library/Application Support/Napominalka`.

## Запуск из исходников (с синхронизацией задач в GitHub)
```bash
pip install -r requirements.txt
pythonw napominalka.pyw        # Windows (или двойной клик по «Запустить.bat»)
python3 napominalka.pyw        # Linux / macOS
```
При запуске из исходников задачи лежат в **`data/tasks.json` внутри репозитория**,
а внизу окна появляется кнопка **«☁ Сохранить в GitHub»**: она делает `git commit` файла
с задачами и `git push`. ⚠ Если репозиторий публичный, задачи видны всем.

## Как пользоваться
- **Текстом:** пишешь `Забрать посылку через 3 дня` → Enter.
- **Голосом:** 🎤 → говоришь → ■ → проверяешь → Enter. Распознавание через Google, нужен интернет.
- Понимает: `сегодня`, `завтра`, `послезавтра`, `через N дней`, `через неделю`, `20 ноября`,
  `5 января 2027`, `15.11`, `15.11.2026`, `в понедельник`, `до пятницы`.
- Кружок слева у задачи — выполнено; ⟲ — перенести срок; ✕ — удалить (можно «Отменить»).
- Тема: Авто / Светлая / Тёмная (вверху справа).
- Крестик окна прячет программу в трей (на macOS — сворачивает в Dock), напоминания продолжают
  работать. Выход — правый клик по значку в трее → «Выход».
- Переключатель **«Запускать вместе с …»** — автозапуск при входе в систему, сразу в трей.

## Сборка самому
```bash
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm napominalka.spec      # результат в dist/
```
PyInstaller собирает только под ту ОС, на которой запущен. Сборки под все три системы
делает GitHub Actions (`.github/workflows/build.yml`) при каждом push в `main`;
тег `v1.0.0` → `git push --tags` создаёт Release с файлами.

Проверка сборки без окна: `Napominalka --selftest` (результат в `selftest.txt` в папке данных).

## Настройки
Интервалы и тихие часы — в начале `reminder_core.py`
(`INTERVAL_DAY_BEFORE`, `INTERVAL_DUE_DAY`, `QUIET_FROM`, `QUIET_TO`). Тесты: `python test_core.py`.

## Файлы
| файл | что внутри |
|---|---|
| `napominalka.pyw` | окно, голос, трей, всплывающие напоминания |
| `reminder_core.py` | задачи, расписание, разбор дат из речи |
| `platform_utils.py` | всё, что зависит от ОС: уведомления, звук, автозапуск, git |
| `icon_art.py` | иконка (рисуется кодом) |
| `napominalka.spec` | конфиг PyInstaller |
